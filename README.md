# PNCB - PiNum Compiler Backend
This compiler backend is a clone and modification of QBE. This is being specifically optimized for the PiNum programming language's use case. for more information about QBE check out - https://c9x.me/compile/ .

This is still being worked on to make usable for PiNum-Lang frontend and has not been integrated into the codegen pipeline yet. 
The README will be updated after PNCB is integrated and part of the compiler.
